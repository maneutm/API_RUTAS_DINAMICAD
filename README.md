# Api + Rutas dinamicas

## Trabajo Realizado con : 
. NEXT.JS
.TypeScript
.Tailwind
.PokeApi (https://pokeapi.co/#google_vignette)

## Proposito del Trabajo
. Comprender de manera mejor manera el framework NEXT.JS.
. Aprender el uso delas rutas dinamicas.
. Comprender la diferencia entre un layout.tsx (Estructura base para las paginas de aplicacion) y un page.tsx (Define el contenido de la pagina).

## Funcionalidades del sistema
. Consumo de API externa
- Rutas dinámicas (`/Pokemones/[name]`)
- Diseño responsivo con Tailwind
